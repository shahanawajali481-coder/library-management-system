# 📚 Library Management System

A desktop-based Library Management System built with Python, Tkinter, and SQLite. The application provides a simple and user-friendly interface for managing books, library members, and issue/return transactions.

## ✨ Features

- 📖 Add, update, search, and delete books
- 👥 Manage library members
- 🔄 Issue and return books
- 📊 Track total and available book copies
- 🔍 Search and filter books
- 🏷️ Organize books by category
- ⚙️ Application settings management
- ✅ Input validation and error handling
- 💾 SQLite database for persistent data storage
- 🖥️ User-friendly desktop interface

## 🛠️ Technologies Used

- **Python**
- **Tkinter** – Desktop GUI
- **SQLite** – Database
- **SQL** – Data management
- **Object-Oriented Programming (OOP)**
- **Git & GitHub** – Version control
